## MuSuBi Music Center - Ruby Experimental Ver.
## Java Spring Boot と Ruby を融合させたハイブリッド音楽共有プラットフォーム
本プロジェクトは、メインプロジェクト MuSuBiMusic のビジネスロジックを Ruby (JRuby) に移植した技術検証用スピンオフ・プロジェクトです。

📌 プロジェクトの意図と背景
すでに Java Spring Boot で構築された堅牢なシステムに対し、「特定のロジックをスクリプト言語（Ruby）に委ねることで、開発の柔軟性をどこまで高められるか」という技術的挑戦を目的に制作しました。

単なるコードのコピーではなく、**「ポリグロット（多言語）プログラミング」**の観点から、Java と Ruby という異なる特性を持つ言語の相互運用性を検証しています。

🛠 技術的なハイライト (Technical Highlights)
JRuby による言語間連携: ScriptingContainer を活用し、Java のコントローラーから Ruby のメソッドを直接呼び出すブリッジ構造を構築しました。

ロジックの外部化: 音楽リストの管理（CRUD 操作の核となる部分）を Ruby スクリプト（follow_logic.rb）に分離し、Java 側は Web インターフェースの制御に特化させました。

シームレスなデータ共有: Java 側で定義した Music オブジェクトを Ruby 側でインスタンス化し、再び Java のモデル（Thymeleaf）に渡すという、複雑なオブジェクトの受け渡しを安定して実現しています。

📖 このプロジェクトを通じて得た知見 (Learning)
ハイブリッド環境の構築: Java の型安全な設計と、Ruby の直感的なロジック記述を一つのプロジェクト内で共存させる手法を学びました。

実行環境のライフサイクル管理: サーバー起動時に Ruby インスタンスを一度だけ生成して共有する（Singleton 的なアプローチ）ことで、ステートレスな Web 環境下でのデータ永続性を確保する方法を実践しました。

技術的柔軟性: 既存のシステムに対して「もし他の言語で実装したらどうなるか」という多角的な視点を持ち、実際にプロトタイプを作成する能力を養いました。

🚀 主要機能 (Features)
リアルタイムチャート: 現在共有されている曲のリストを表示・管理します。

ミュージックシェア: YouTube ID を利用し、Ruby 側のロジックを通じて即座に楽曲をチャートに追加します。

インライン再生: 安定した YouTube IFrame 連携により、ページ遷移なしで音楽を視聴可能です。
